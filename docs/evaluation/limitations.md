# Known Limitations

## Overview

This document captures the current limitations of the project without changing the application behavior.

## Major Limitations

- Security model is not strong enough for production use
- Admin authorization is weak and should be improved
- Environment secrets are part of local config and are not safe for version control
- No automated tests exist
- Payment flows are incomplete
- No pagination or catalog scaling strategy exists
- No formal performance benchmark was performed
- No deployment configuration has been verified as production-ready
- The project is best understood as a working tutorial/portfolio-style app, not an enterprise commerce platform

## Conclusion

The project is educationally useful and technically coherent, but it still has significant engineering gaps that should be documented honestly.
