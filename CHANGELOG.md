# Changelog

## Current Version

Initial full-stack implementation of NexCart.

### Frontend

- Customer storefront implemented in React
- Product listing and product detail pages
- Cart state and cart summary logic
- Login and registration flow
- Order history and checkout flow

### Admin

- Admin login page
- Add product form with media upload
- Product list and removal actions
- Order list and status update UI

### Backend

- Express API structure for authentication, products, cart, and orders
- MongoDB integration using Mongoose
- Product image uploads via Multer and Cloudinary
- JWT-based auth and bcrypt password hashing

### Evaluation

- Repository review completed
- Architecture, security, performance, testing, and deployment observations documented
- Known limitations recorded without changing app functionality

### Known Limitations

- Security risks remain and are documented
- Admin authorization is not robust
- No automated testing suite exists
- No production deployment configuration was verified
- Payment workflows are incomplete
- No pagination or backend catalog scaling strategy exists

This changelog reflects the current project state and does not include future upgrades or feature additions as implemented work.
